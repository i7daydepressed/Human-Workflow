# Optional bounded delegation

A subagent needs actual platform tools, access and applicable authorization/instructions. This package supplies procedure, not a launcher, new permissions or domain competence. Ordinary work needs no fixed agent count/model. Work alone or hand an exact human-step packet to the agreed executor when delegation is unavailable/unnecessary.

Consider independent extraction, source inspection or explanation checks when useful; keep short dependent actions together. Briefly explain what is delegated and why. A subagent is not an external human expert or correctness guarantee. Record model/reasoning configuration only from evidence; unknown is valid. Check current platform documentation if needed rather than assuming a particular client supports delegation.

Give goal, necessary raw sources/versions, scope, adaptation limits, output path/format and checks. Establish access across machines/services. Avoid concurrent owners of a DOCX, report or state; use separate outputs and one integrator. For independent evaluation supply ordinary task inputs, not expected answers, diagnoses or competing outputs. Do not request hidden reasoning.

The main agent inspects artifacts, preserves contradictions and owns integration/decisions within authorization. Attribute other runs rather than relabeling them personal observations. Each executor returns facts, limits and concise participation notes; one main feedback request serves the whole process. Parallel work may change waiting/context cost but does not guarantee fewer total tokens. Do not delegate merely to satisfy a checklist or treat repeated calls as independent proof.
