# Adapted observations and limits

These are summaries retained from earlier workflow/case records, not new application runs or a controlled experiment. Private source links, exact artifact hashes and personal details are omitted. See the [case drafts](../examples/index.md) for attributed examples; the source records remain private and unchanged.

| Recorded observation | Reusable action | Limit |
| --- | --- | --- |
| Cover appearance changed with body Normal edits | Clone agreed blocks, isolate styles when necessary and view the cover | Blank paragraphs can have a layout role |
| Seven images shared five captions | Count caption groups separately from files | Independent figures still need connecting explanation |
| Manual Word edits changed captions, panels, tables, sizes and TOC | Select current DOCX and retain divergence/patch maps | Rebuilding stale MD loses accepted manual work |
| A short edition was selected while full text remained | Record primary edition and retain alternatives | Length and score do not decide quality alone |
| Duplicate TOC titles occurred in theory/practice | Match full section numbers/bookmarks to physical pages | updateFields alone is not a verified cache |
| Separate user/teacher ratings were clarified later | Preserve attribution, scale, history, report/actual dates | Do not invent causes or a missing maximum |
| Historical acceptance coexisted with a recorded GUI crash | Keep known defects and original check coverage visible | Acceptance does not establish a fix |
| A mutable current DOCX differed from an older final hash | Treat it as a different current version | Neither corruption nor submitted-byte identity follows |
| PREPARE/calculations lacked a required execution frame | Capture/reproduce actual output within access | A calculated table is a different evidence type |
| Image style received positive user feedback | Preserve useful methods and opinion with scope | No causal score effect was established |

Existing helper tests establish local contracts, not a universal converter/cloud chain or host behavior. Optional subagents are not assumed to be available to every user. Current Word preset/render limits are documented separately. Conditional cloud writes, broader editors/field refresh and general composition remain future work. Self-review, user reply and acceptance keep different sources; saving feedback does not train weights or authorize installed-rule edits.
