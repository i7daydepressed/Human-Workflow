# Адаптированные исторические наблюдения

Пересказ основан на наблюдениях, записанных в прежней документации workflow. Подробные личные журналы/коммиты не включены; исторические запуски для этого кандидата не повторялись. Это не текущие факты исполнения и не доказательство эффективности данной версии.

| Записанная ситуация | Переносимое действие | Ограничение |
| --- | --- | --- |
| Пакет продолжал локальные незакоммиченные правки, отсутствовавшие в удаленной базе | Проверить реальные методы, сохранить прежние изменения | Чистое дерево не обязательно; не откатывать к старому SHA |
| Установленный API потребовал nullable-адаптации generic | Сделать минимальную проверенную адаптацию, вернуть причину/проверку | Не заменять все похожие типы во всех версиях |
| Расчет/сборка/headless прошли, нативное управление завершилось тайм-аутом; позднее записан GUI-запуск | Назвать вид свидетельства, версию и исполнителя | Поздняя запись не является новым GUI-действием этого агента |
| После прежних тестов переместили материалы сборки | Сохранить покрытие с его версией, перепроверить затронутое | Старый успех не является новым запуском после переноса |
| После перемещения архива поздний UI-пакет оставался невыполненным | Разделять подготовку/исполнение/приемку | Имя/расположение файла не доказывает исполнение |
| Сбой воспроизведен на базе при успехе другой группы проверок | Сохранить сбой, происхождение и отдельный следующий шаг | Пройденные проверки не закрывают сторонний дефект |
| Вспомогательные тестовые/build-проекты попали во входы основной сборки | Осознанно размещать harness; менять правила сборки по поручению | Универсальная правка исключений не следует |
| Правки комментариев требовали объяснения и сохранения исполняемого кода | Объяснить поток данных/неочевидные условия, проверить соразмерно | Расчет/проверка комментария не являются GUI-запуском |
| Позже добавлен ручной/непрограммный объем | Применять подтвержденные объект/действие/наблюдение | Новая инструкция не доказывает испытание оборудования |
