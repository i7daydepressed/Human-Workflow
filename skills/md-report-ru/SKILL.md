Общие Python-помощники находятся в обязательной соседней папке [scripts](../scripts/README.md). При переносе навыка сохранять эту папку целиком по [README.md](README.md). В командах `<shared-scripts>` означает ее проверенный абсолютный путь.

Это вспомогательная русская редакция. Прочитать фактическое поручение и явно указанный профиль, если он предоставлен, затем [русскую рабочую инструкцию](workflow.md). Использовать русскую редакцию инструкций из этой папки; основная английская редакция — отдельный скилл `md-report`. Язык результата и журнала выбирать независимо по поручению пользователя и выбранному профилю. При обычном выполнении не читать обе редакции.

Искать инструкции относительно папки этого SKILL.md: workflow.md и references/. report_workspace.py находится в scripts/, остальные помощники — в обязательной соседней папке ../scripts/. Данные и шаблоны находятся в resources/. Помощники запускать по абсолютным путям независимо от рабочей папки задачи. При переносе из плагина перенести также общую папку scripts по [README.md](README.md); сохранить имена и взаимное расположение папок. Не скачивать недостающие инструкции. Если обязательный ресурс недоступен, сообщить его фактический путь и затронутую операцию; не заявлять о выполнении процесса только по его описанию. Задачи, результаты и приватные профили хранить вне установки. Сочетать этот процесс с доступными скилами для нужных форматов; наличие конкретного скилла или средства отрисовки не гарантируется. См. [границы клиентских проверок](resources/docs/client-checks.ru.md). Не подставлять приватный оригинал вместо публичного ресурса.
