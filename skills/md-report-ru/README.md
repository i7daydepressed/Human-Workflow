# Перенос md-report-ru из плагина

Папка `skills/scripts` — обязательная зависимость общих Python-помощников навыка. При переносе копировать ее целиком вместе с папкой навыка, сохраняя имена и взаимное расположение:

```text
<папка-переноса>/
  skills/
    md-report-ru/
    scripts/
```

Не копировать общие скрипты обратно внутрь навыка. `<shared-scripts>` в командах означает проверенный абсолютный путь к соседней папке scripts; рабочая папка задачи может находиться в другом месте.

Сохранять весь состав resources/ перенесенного навыка. Для Word-команд нужны Word-ресурсы md-report либо md-report-ru; общий word_cover.py находит встроенные образцы в этих стандартных соседних каталогах. Содержательные отчеты, профиль и опыт требуют соответствующих инструкций, указанных в SKILL.md; наличие общих скриптов само по себе их не заменяет.

Основная инструкция — [SKILL.md](SKILL.md), состав и назначение общих помощников — в [scripts/README.md](../scripts/README.md). Папка scripts не является отдельным навыком. Локальная запись и контрольный снимок не подтверждают облачную синхронизацию.
