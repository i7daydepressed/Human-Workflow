# Общие скрипты навыков

Здесь находятся помощники, используемые несколькими каталогами навыков. При переносе навыка из плагина папка skills/scripts является обязательной зависимостью: переносить ее целиком и сохранять соседнее расположение с папками навыков.

| Файл | Назначение |
| --- | --- |
| [agent_journal.py](agent_journal.py) | Создание и дополнение отдельного журнала запуска |
| [profile.py](profile.py) | Явный локальный профиль и перенос выбранных ресурсов |
| [case_catalog.py](case_catalog.py) | Проверка каталога случаев и построение индекса |
| [inspect_word_sample.py](inspect_word_sample.py) | Структурное изучение Word-образца |
| [word_cover.py](word_cover.py) | Применение выбранного титула |
| [docx_package.py](docx_package.py) | Проверка частей и связей DOCX |
| [docx_guard.py](docx_guard.py) | Сравнение выбранных признаков DOCX |
| [safe_paths.py](safe_paths.py) | Проверка границ установки и путей записи |
| [i18n.py](i18n.py) | Сообщения отчетного аудита |

CLI запускать через `python3 <shared-scripts>/<имя>.py --help`, где `<shared-scripts>` — абсолютный путь к этой папке. safe_paths.py и i18n.py — служебные модули. Для word_cover.py требуется прежняя зависимость lxml; новое объединение ее не устанавливает.

report_workspace.py остается внутри md-report/scripts и md-report-ru/scripts: редакции различаются языком и выбирают собственные шаблоны. Они импортируют общие модули отсюда. Встроенные Word-образцы остаются в resources/assets/word отчетных навыков; при переносе сохранять эти ресурсы.

Защита путей запрещает результаты внутри полного плагина, а при отдельном переносе — внутри общего каталога skills. Запись за этой границей не подтверждает долговременность или облачную синхронизацию.
