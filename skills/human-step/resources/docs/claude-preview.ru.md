# Установка в Claude

Устанавливать тот же репозиторий по [инструкции](installation.ru.md). Корневой каталог указывает на `./`; каждый скил содержит свои генерируемые ресурсы. См. [размещение](skill-resources.ru.md) и [фактическую область проверок](client-checks.ru.md). Отдельный тестовый пакет для Claude не требуется. [English](claude-preview.en.md).

Полнота папки и локальные тесты не доказывают исполнение в конкретной среде Claude. Попросить установленный скил прочитать инструкции и сообщить недоступные пути. Доступ к файлам, сохранение профиля, Python, рендер и шрифты определяются средой и аккаунтом.
