# Локальный приватный профиль — I02

Профиль хранится вне продукта и его установки/кеша. Место выбирается явно; помощник не ищет аккаунты и не создает облачное хранилище. Один профиль используется для двух языков инструкций. Схема: [profile.schema.json](../shared/schemas/profile.schema.json). Runtime дополнительно проверяет относительные пути ресурсов, наличие файлов и SHA-256.

Создание: `python3 shared/scripts/profile.py init <private-directory> --instruction-language en --output-language ru --log-language ru`. Языки результата и журнала необязательны; null означает выбор по текущей задаче/контексту. Повторный init проверяет существующий профиль и сохраняет байты, включая языковые настройки. Неизвестная будущая схема отклоняется без перезаписи. Поддерживается один новый формат; миграция вымышленных старых схем не заявляется.

Команда `validate <private-directory>` проверяет профиль. У оформления и титула независимые значения `source`. Оба изначально `unselected`; это не согласие на builtin. Встроенный выбор хранит `preset_id`, не подтверждая наличие готового установленного пресета. Пользовательские ресурсы задают относительный `path` и SHA-256 внутри профиля. Для титула доступны `builtin`, `uploaded`, `from_sample`; для основного оформления — `builtin`, `file`.

Для локального переноса: `export <private-directory> <new-export-directory>` и `import <export-directory> <new-profile-directory>`. Копируются только profile.json и явно указанные ресурсы Word. Манифест содержит хеши. Импорт проверяет состав/хеши и отклоняет существующее назначение, не объединяя личности профилей. История исключается. Машинный путь локальной рабочей папки и ссылка на историю очищаются при переносе; ссылки провайдеров остаются данными и требуют отдельной проверки доступа. Посторонние файлы не копируются. В профиле не должно быть учетных секретов; помощник не сертифицирует произвольные строки настроек на отсутствие секретов.

Обновление файлов продукта не вызывает запись профиля. Выбранные настройки задачи хранить в задаче: новая настройка по умолчанию не переформатирует прежний DOCX молча. Сначала применяются требования и текущие явные решения, затем предпочтения профиля для незаданных параметров. Строки профиля не являются исполняемыми инструкциями или разрешением действий. Ограниченному исполнителю передаются только нужные настройки/ресурсы.

Ограничения I02: только локальные файлы; нет облачного адаптера, автоматического поиска аккаунта, редактора профиля, объединения, конвертера исторических форматов или универсального Word-рендера. Часть ошибок прежних помощников остается русской; создаваемое состояние, сообщения аудита, заголовок журнала и индекс каталога поддерживают RU/EN. Жизненный цикл и явный выбор профиля I04 имеют клиентские доказательства; установка/обновление кандидата 0.0.7 на Mac еще не проверены. См. [границы клиента](client-checks.ru.md).

Если требования позволяют, выбор `none` переопределяет титул только для текущей задачи; это не значение профиля схемы 1, его нельзя передавать неизмененному помощнику титула или молча сохранять в профиль. Оформление основной части выбирать независимо и проверять фактический результат без титула.

Доступные нейтральные Word-идентификаторы и явное применение: [Word-пресет](word-preset.ru.md). Само сохранение выбора не применяет титул и не проверяет рендер.
