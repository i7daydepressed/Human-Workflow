# Общие исходники и ресурсы внутри скилов

[English](skill-resources.en.md).

Редактировать исходники в `locales/`, `shared/` и `docs/`. Из корня репозитория запускать `python3 tools/sync_skill_resources.py`, чтобы обновить `skills/<name>/resources/`. При разрешённой публикации сохранять генерируемые файлы вместе с изменением исходников: для прямой установки из GitHub необходимые байты уже должны быть в репозитории. Пользователь ничего не собирает.

Каждый вход ссылается на собственную папку ресурсов. Инструкции, шаблоны, скрипты, схемы и Word-ресурсы остаются доступны при копировании одного скила без родительского плагина. Команды помощников разрешаются относительно корня ресурсов, а не текущей папки задачи. `resource-manifest.json` содержит исходные пути и хеши; `packaging/skill-resources.json` — общую карту происхождения для разработчика.

Поддерживается одна база исходников и несколько автоматически полученных физических копий для установки. Это заменяет прежнее требование ровно одной физической копии runtime в пакете. Копии вручную не редактировать; приватные профили, задачи, журналы и секреты в них не добавлять. Синхронизатор сообщает о посторонних файлах, а не удаляет их. `--check` проверяет актуальность без записи; сборщики плагина отклоняют устаревшие копии.

Локально проверять изолированные скилы: относительные ссылки, импорты Python из другой рабочей папки, сохранность внешнего профиля и запрет вывода внутрь установки. Эти проверки не эмулируют все среды и не доказывают установку в веб-чат Claude. Область проверок описана отдельно в [клиентских доказательствах](client-checks.ru.md).

## Диагностика содержащего пакета

Манифесты ресурсов со схемой 1 и общий реестр дополнены метаданными `package`: name, version, display_name, source=`plugin.json` и source_sha256 фактических байтов канонического манифеста. Генератор читает его один раз; не поддерживает вторую константу версии, не копирует вручную поддерживаемый манифест в каждый скил, не добавляет время и не хеширует содержащий манифест внутрь него самого. Смена корневой идентичности нарушает актуальность до регенерации. Метаданные называют содержащий кандидат, но не подтверждают установку, выбор или исполнение в клиенте. Имена двух скилов, схема профиля 1 и i02-идентификаторы Word-ресурсов сохраняются независимо.
