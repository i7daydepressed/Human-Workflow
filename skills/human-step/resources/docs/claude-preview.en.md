# Claude installation

Install the same repository using the [installation guide](installation.en.md). The root marketplace points to `./`; each skill contains its own generated resource folder. See [resource layout](skill-resources.en.md) and [actual check scope](client-checks.en.md). No separate Claude test package is required. [Русский](claude-preview.ru.md).

A complete folder and local tests do not establish execution on your Claude surface. Ask the installed skill to read its instructions and report missing paths. Account/host capabilities determine file access, profile persistence, Python, rendering, and fonts.

The candidate identity is `human-workflow` `0.0.7` / Human-workflow-v0.0.7, Apache-2.0. Publication and real Claude installation remain unverified for this candidate. Custom-skill ZIP upload is a different route from plugin installation; no dedicated upload builder or Free-plan host check is supplied. Follow the [controlled migration](migration.en.md) for existing installations.
