# Улучшение изображения персонажа

## Маршрут работы

1. До первого редактирования прочитать [общее руководство по улучшению](references/enhancement.md). Выполнить его шаг выбора стратегии: при отсутствии уже заданного выбора обязательно спросить пользователя о сохранении палитры волос и дождаться ответа. Запрос «улучши качество» сам по себе не выбирает стратегию.
2. Заполнить [карточку наблюдений](references/observation-card.md) по исходнику, затем из таблицы руководства перейти к выбранной стратегии: сохранению цветов или согласованию волос. Прочитать ее полностью; собрать полный промпт из карточки и образца, проверить его до вызова редактора. Общие наблюдения и инструкция улучшения в двух стратегиях одинаковы; различается только разрешенное изменение цвета волос. Если пользователь поручил обе стратегии, выполнять их независимо от одного исходника.
3. Вернуться к общему руководству для проверки, при необходимости адресной коррекции и показа результата. Применять приемы по наблюдаемому отклонению текущего кадра.

Редактировать реальный исходный кадр. Сохранять лицо, выражение, позу, геометрию, дизайн одежды, сцену, кадрирование и рисовку. Новый костюм, поза, форма прически, замена основного цвета волос или новый персонаж требуют отдельной задачи. Число результатов и место хранения брать из поручения.

Эталонные промпты, промпты-образцы и заполненные запросы к редактору составлять на английском, включая заменяемые поля и дополнительные вставки. Инструкции, объяснения и справочные таблицы оставлять на русском.

## Указатель материалов

Следовать маршруту выше; прямые ссылки ниже использовать для возврата к нужному шагу.

| Материал | Роль в маршруте |
| --- | --- |
| [Общее улучшение](references/enhancement.md) | Обязательная общая процедура: вопрос, выбор, осмотр, обработка, проверки, коррекция и показ |
| [Карточка наблюдений](references/observation-card.md) | Обязательные наблюдения, перенос в промпт и проверка перед редактором |
| [Сборщик запроса](scripts/prepare_request.py) | Проверка формы и детерминированный перенос наблюдений в выбранный полный образец |
| [Сохранение цветов](references/preserve-colors.md) | Первая из двух стратегий; читать после выбора в общем руководстве |
| [Согласование волос](references/harmonize-hair.md) | Вторая стратегия; читать после разрешения цветовых акцентов в волосах |

Структурная проверка не доказывает качество изображения. Подтверждать сохранность деталей сравнением конкретного результата с исходником, различая наблюдения, измерения и отзыв пользователя.
