## Пользовательская оценка

**1 — ожидаемый хороший уровень, меньше 1 — ниже него, больше 1 — лучше ожиданий.** Оценка относится к конкретному результату и версии. Без отзыва — «не оценено»; число не выводится из похвалы и не переносится между изображением и HTML. Проверки, оценка и уникальность учитываются отдельно.

## Пополнение

Для сохранения результата или отзыва вне пакета используй [правила коллекции](library-additions.md). Для включения нового авторского пресета — [правила добавления](preset-additions.md). Эти сведения нужны только при пополнении, не при обычном выборе пресета.
