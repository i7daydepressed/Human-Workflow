# Обозреватель файлов

Код: `file-viewer` · Редакция HTML: **1** · Оценка: **не оценено**.

Для изучения нескольких текстов и изображений используй [HTML-оболочку](../../resources/file-viewer.html): дерево, закрываемые вкладки, номера строк, поиск в открытом файле, копирование, простое чтение Markdown и тема. Для другой задачи вернись в [каталог](../library.md).

## Наполнить

Шаблон пуст. Выбранные реальные файлы вставляет в его копию [build_viewer.py](../../scripts/build_viewer.py); оболочка и исходники не меняются. Порядок запуска и требования — в справке [Python-сборщика](../build-script.md).

Передай `--root`, новый `--output` и относительные пути явно выбранных файлов. Принимаются UTF-8 и PNG/JPEG/WEBP/GIF; раскрытые символические ссылки должны оставаться внутри корня. Файлы встраиваются целиком, без изменения байтов. Для больших материалов оцени подходящую упаковку: готовый помощник не создаёт соседнюю папку ресурсов.

Сборка фиксирует время с часовым поясом, пути, размер и SHA-256. Снимок не обновляется вслед за исходниками.

## Данные при адаптации

JSON находится в `script#ed-data`: `title`, `snapshot`, `groups`, `files`, `initial`. Группа содержит `id`/`label`. Файл — `id` с полным относительным путём, `group`, `path`, `type`, `bytes`, `sha256`, `purpose`. Для текста нужны `type: "text"`, `content`; для растра — `type: "image"`, `preview` с data URI. Сборщик формирует поля и безопасное экранирование автоматически.

## Поведение и ограничения

- Просмотр не редактирует исходники и не выполняет код/скилы. Копируется полный текст открытого файла; доступность системного буфера зависит от среды.
- Поиск ограничен текущим текстом. Вкладки, тема и поиск сбрасываются при перезагрузке.
- Markdown поддерживает простые заголовки, списки, таблицы, код и ссылки. Сложная разметка упрощается; точное содержимое доступно в режиме «Текст». Внутренние ссылки открывают встроенные файлы, фрагменты заголовков не обрабатываются. Внешний адрес только показывается, перехода нет.
- Растры сохраняют пропорции, размеры показываются после загрузки. Сравнение и универсальный масштаб сюда не входят.
- Требуется JavaScript; внешних библиотек и постоянного хранилища нет. Загрузку, действия и буфер проверяй в выбранном месте показа.
