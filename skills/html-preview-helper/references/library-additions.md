# Сохранение примеров и отзывов

Читай при поручении сохранить конкретный HTML, версию или отзыв. Для включения универсальной оболочки в пакет нужен отдельный порядок: [добавление пресета](preset-additions.md).

## Место и повторы

Используй выбранную постоянную коллекцию вне установленного скила. Если её ещё нет, создай `html-preview-library` в постоянной рабочей папке проекта; неизвестное место уточни. Сохранение выполняется по поручению или уже действующей договорённости и не означает публикацию.

Индекс `library.md` содержит таблицу **задача → карточка → пресет/редакция → статус → оценка**. В подпапке примера храни HTML, его зависимости и одноимённую Markdown-карточку. Индекс уровнем выше ведёт в карточку, она — в HTML; внутренние ссылки относительные.

Сравни с существующей коллекцией и каталогом. Точный повтор HTML **и всех ресурсов** не копируй снова; новый отзыв добавь в прежнюю карточку, если он дан. При необходимости сверяй SHA-256: сумма HTML не фиксирует отдельные ресурсы. Другие данные в прежней оболочке обычно означают новый кейс, а не новый пресет.

Готовый результат сохраняй без пересборки, проверяя совпадение копии. Можно связать карточку с уже постоянным файлом, явно указав отсутствие отдельного снимка. При создании результата из пресета способ сборки описан отдельно: [Python-сборщик](build-script.md). Новая версия получает отдельные HTML и карточку со ссылкой на предыдущую; старые артефакты и отзывы сохраняются.

## Карточка

Заполняй основу подтверждёнными сведениями; неизвестное указывай прямо. Вместо примерных имён подставь реальные ссылки. Проектные материалы остаются в личной коллекции, в авторский пресет они не переносятся.

```md
# Название примера

- Задача: какое действие пользователя облегчает HTML.
- Результат: [имя.html](имя.html), версия, дата, необходимые ресурсы.
- Происхождение: материалы, автор результата, основание сохранения; неизвестное указать.
- Пресет: справка, код и редакция либо «собственный, ещё не включён».
- Ближайший аналог и полезное отличие: что переиспользовано и что добавлено; отсутствие отличий отметить.
- Статус: кейс / кандидат / включён; для кандидата и включения — основание и авторское решение.

## Отзывы

Не оценено. При отзыве: дата, автор, версия и предмет оценки, число по шкале и комментарий. Без числа сохранить словесный отзыв.

## Проверки и ограничения

Кто, где и что проверил, результат и непроверенные возможности. При необходимости — суммы и ссылка на отдельный протокол.
```

Применяй шкалу из каталога. Не выводи число из похвалы, не усредняй разные отзывы автоматически и не переноси оценку кейса на универсальный пресет. Новая версия не наследует оценку или приёмку. После изменения статуса/отзыва синхронно обновляй карточку и индекс.

Перед завершением перечитай записи, проверь ссылки и комплектность HTML с ресурсами. Подробные журналы в карточку не копируй. Сообщи место сохранения, реальные проверки и ограничения.
