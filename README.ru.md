# Workflow Tools — предварительная версия

Два процесса в одном плагине: **human-step** готовит, исполняет и проверяет точные пошаговые задания; **md-word** сопровождает задачи, сохраняет состояние и готовит отчеты по запросу. У них синхронные английская и русская редакции инструкций, один общий runtime, внешний приватный профиль и нейтральный Word-пресет. [English](README.md).

## Установка из GitHub

Дайте агенту GitHub-ссылку на этот репозиторий и поручение: «Установи Workflow Tools из этого репозитория по README для моего клиента». Агент с доступом к терминалу может использовать команды ниже. Замените `REPOSITORY_URL` действительной GitHub-ссылкой.

Claude Code:

```bash
claude plugin marketplace add REPOSITORY_URL
claude plugin install workflow-tools-preview@workflow-tools
```

Codex CLI:

```bash
codex plugin marketplace add REPOSITORY_URL --json
codex plugin add workflow-tools-preview@workflow-tools --json
```

В интерфейсе плагинов Claude выберите **Customize → Plugins → Add → Add marketplace**, укажите ссылку и установите Workflow Tools Preview. Доступность зависит от настроек аккаунта/клиента. После установки начните новый разговор/сессию. [Подробности установки](docs/installation.ru.md).

Собирать ZIP не требуется. Оба каталога указывают на корень этого репозитория с теми же двумя скилами и общими ресурсами. Сохраняйте полное дерево плагина. Задачи и приватные профили храните вне установки/кеша; см. [контракт профиля](docs/profile.ru.md).

## Использование

Попросите подготовить точный пакет передачи, исполнить согласованный пакет или сопровождать задачу с сохранением состояния. Сопровождение не требует итогового отчета. Общие вопросы и отдельные правки кода не должны запускать весь процесс. По умолчанию используются английские инструкции; явная настройка задачи/профиля выбирает русские. Языки результата и журнала независимы.

[Word-пресет](docs/word-preset.ru.md) дает очищенный образец оформления. Пользователь может выбрать свои эталоны и предпочтения. Рендер, шрифты и дополнительные зависимости зависят от среды; установка плагина их не предоставляет. Основные помощники используют стандартную библиотеку Python; дополнительная ограниченная сборка обложки требует `lxml`.

## Состояние

Базовый вариант проверен на Mac с Codex CLI 0.162.1. [Доказательства](docs/client-checks.ru.md) описывают фактический объем проверок. Структура для прямой установки из GitHub подготовлена; установка по будущей GitHub-ссылке и фактическое поведение Claude еще не наблюдались. Для предварительной версии сохранены технические имя `workflow-tools-preview` и версия `0.0.0-i05`. Владелец выбрал приведенную ниже модель лицензирования. Публичная загрузка, окончательная идентичность и открытие коммерческих продаж остаются отдельными шагами.

Личные оригиналы, приватные профили и персональные журналы исключены. Обезличенные исторические примеры — справочные материалы, не действующая история пользователя. Проверки разработки и необязательные сборщики архивов остаются в `tests/` и `tools/`; для установки из GitHub они не нужны. [Статус выпуска](packaging/release-status.json).
