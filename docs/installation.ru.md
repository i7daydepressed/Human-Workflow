# Установка и клиентские среды

[English](installation.en.md). Репозиторий: <https://github.com/i7daydepressed/Human-Workflow>.

Кандидат — `human-workflow` `0.0.7`, отображаемое имя — Human-workflow-v0.0.7. Оба каталога репозитория указывают на корень плагина `./` и сохраняют имя `workflow-tools`. Правки исходников не публикуют кандидат: до установки проверить реально распространяемую редакцию. Для существующей установки использовать [миграцию](migration.ru.md), а не создавать дубликаты вслепую.

## Документированный способ и наблюдаемая поддержка

| Среда | Документированный способ и возможности | Доказательства для кандидата |
| --- | --- | --- |
| Пользовательские скилы Claude chat | Бесплатные и платные планы при включённом исполнении кода; загрузка ZIP с папкой скила. Политика организации может ограничивать доступ. | Отдельные ZIP для загрузки не собраны и не проверены в клиенте; ZIP всего репозитория не является таким форматом. |
| Плагины Claude chat | Платные планы; в чате работают скилы и команды. Hooks и субагенты там не исполняются. | Новая установка в аккаунт и исполнение не наблюдались. |
| Claude Cowork / Code | Среды с поддержкой hooks/субагентов при фактических возможностях и разрешениях. Этому плагину ни hooks, ни субагенты не требуются. | Проверки чата или исходников не переносятся на эти среды. |
| Codex CLI / Desktop | Переносимый корневой `plugin.json`, `skills/` и настройки OpenAI в `extensions.com.openai`; дополнительный compatibility overlay здесь не нужен. | Записывать фактическую версию приложения/CLI, способ установки и наблюдаемые байты. История CLI не подтверждает исполнение в Desktop. |

## Будущая разрешённая установка из репозитория

Codex CLI:

```bash
codex plugin marketplace add https://github.com/i7daydepressed/Human-Workflow --json
codex plugin add human-workflow@workflow-tools --json
codex plugin list --marketplace workflow-tools --json
```

Claude Code:

```bash
claude plugin marketplace add https://github.com/i7daydepressed/Human-Workflow
claude plugin install human-workflow@workflow-tools
```

Если CLI недоступен, использовать поддерживаемый интерфейс клиента. Команды описывают будущую разрешённую установку после доставки кандидата; при реализации исходников они не выполнялись. Каталог изолированного архива `workflow-preview-i04` — отдельная прежняя регистрация. [Управление через CLI](https://learn.chatgpt.com/docs/developer-commands).

## Проверить фактическое использование

Начать свежий контекст. Различать доступные метаданные, фактический выбор, чтение входа/workflow/ресурсов, исполнение, проверки, подтверждённое сохранение и передачу. Для явной проверки назвать `human-workflow:md-word` либо `human-workflow:human-step` и записать реально прочитанные пути. Видимое имя или хороший результат сами по себе не доказывают загрузку и координацию. Автовыбор проверять обычным запросом в другом свежем контексте; успех явного вызова не является его результатом. Недоступные трассы не оценены. Прерывание по квоте не доказывает ни отсутствие доступа по тарифу, ни соблюдение инструкций.

В каждом скиле есть генерируемые `resources/`; запускать помощники по абсолютным путям от этого корня. Задачи, результаты, журналы и явно выбранные профили хранить вне установки/кеша. Языки инструкций/вывода/журнала независимы. [Ресурсы](skill-resources.ru.md), [профиль](profile.ru.md), [Word](word-preset.ru.md), [проверки](client-checks.ru.md), [Apache-2.0](licensing.ru.md).

Основные помощники используют стандартную библиотеку Python; дополнительная композиция титула требует `lxml`. Шрифты и подходящий рендер определяются средой. Соответствие документации и локальные тесты не подтверждают установку или визуальную приёмку Word.
