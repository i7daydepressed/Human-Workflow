# Установка из GitHub

Одна ссылка на репозиторий подходит для Codex и Claude. Корень репозитория — сам плагин; `.agents/plugins/marketplace.json` и `.claude-plugin/marketplace.json` указывают на него. Два скила совместно используют `locales/`, `shared/` и `docs/`. Сборка архива и преобразование исходников не требуются. [English](installation.en.md).

## Codex CLI

Замените `REPOSITORY_URL` действительной ссылкой:

```bash
codex plugin marketplace add REPOSITORY_URL --json
codex plugin add workflow-tools-preview@workflow-tools --json
codex plugin list --marketplace workflow-tools --json
```

Проверьте установленное и включенное состояние, затем начните новую сессию в каталоге задачи. Старый локальный каталог `workflow-preview-i04` зарегистрирован отдельно. Ради пробы этого репозитория не нужно удалять рабочую установку или приватный профиль.

## Claude

В Claude Code:

```bash
claude plugin marketplace add REPOSITORY_URL
claude plugin install workflow-tools-preview@workflow-tools
```

В интерфейсе плагинов Claude откройте Customize → Plugins → Add → Add marketplace, укажите GitHub-ссылку и установите Workflow Tools Preview. Используйте интерфейс плагинов для всего плагина. Начните новый разговор/сессию. Если аккаунт не показывает нужный способ установки, сообщите клиент и фактическое сообщение. Чат без инструментов установки не может выполнить локальную установку только по полученной ссылке.

## Файлы и зависимости

После установки начните обычную задачу. Сохраняйте полное дерево; задачи и профили размещайте вне установки/кеша. При необходимости явно выбирайте внешний профиль. Повторная инициализация сохраняет существующий профиль. Языки инструкций, результата и журнала независимы; оформление и титульник выбираются отдельно. [Профиль](profile.ru.md).

Основные помощники используют стандартную библиотеку Python; дополнительная сборка обложки требует `lxml`. Рендер Word и шрифты зависят от среды. [Границы Word](word-preset.ru.md). Локальные проверки Linux/Python 3.12 и переданные доказательства Mac/Python 3.14.5 не устанавливают совместимость со всеми клиентами/версиями.

Для базы I04 есть ограниченные доказательства Codex CLI. Прямая установка этого репозитория и исполнение в Claude пока не наблюдались. [Доказательства](client-checks.ru.md). Дополнительная серия отдельных ручных тестовых пакетов не является условием начала реальной задачи из GitHub.

Официальные источники, проверены 26.10.2026: [команды Codex](https://learn.chatgpt.com/docs/developer-commands), [каталоги Claude](https://code.claude.com/docs/en/plugins/marketplace-reference), [интерфейс плагинов Claude](https://claude.com/docs/plugins/overview).
