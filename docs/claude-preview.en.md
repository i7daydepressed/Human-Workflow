# Claude installation

Install this same repository from GitHub using the [installation guide](installation.en.md). The root `.claude-plugin/marketplace.json` points to `./`; `.claude-plugin/plugin.json` describes the plugin. Keep its `skills/`, `locales/`, `shared/` and `docs/` together. No separate Claude test archive is required. [Русский](claude-preview.ru.md).

Actual Claude installation and resource access have not yet been observed. Account/host capabilities determine local file access, profile persistence, Python, rendering and fonts. Try a real task after installation and retain actual errors if anything fails. Existing archive builders are optional development utilities.
