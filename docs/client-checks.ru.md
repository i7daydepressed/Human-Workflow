# Клиентские доказательства — кандидат I07

Обновлено 27.10.2026. Локальный кандидат — `human-workflow` `0.0.7`, отображаемое имя Human-workflow-v0.0.7, лицензия Apache-2.0. Основа — проверенный коммит `52f692850ddcd10594697b40377bedfa55550354`. Эта реализация не публикует, не устанавливает и не мигрирует кандидат. Опубликованный ранее I06 и его прежняя лицензия — исторические сведения, а не результаты нового Apache-кандидата.

I07 меняет согласование редакции Markdown, определение роли того же агента, выбор без отдельного титула на уровне задачи, раннее сохранение/сопоставление авторитетов, проверки путей до записи и диагностику идентичности. Механические тесты/сборки подтверждают только фактически проверенные свойства; новые результаты нужно записать после исполнения изменённого кандидата, не копируя число тестов I06 ниже. Исходники и архивы не подтверждают реальное поведение клиента или миграцию.

| Уровень нового кандидата | Статус и граница доказательств |
| --- | --- |
| Установка / клиентская валидация манифеста | not run, пока отдельно не наблюдались фактическая версия приложения/CLI и результат команды |
| Выбор и загрузка | not run; доступные метаданные, выбранный скил и реальное чтение workflow/ресурсов — разные факты |
| Поведение C1-C9 / автовыбор / отрицательные проверки | not run; исходные правила и маркеры не доказывают соблюдение |
| Миграция идентичности C10 | not run; соответствие переименования и инструкция — только подготовка |
| Исходники/помощники/ресурсы/архивы | Записать фактические команды, числа, артефакты и ограничения изменённого кандидата в рабочую запись |

Явный вызов и автоматический выбор требуют отдельных наблюдений в свежих контекстах. Верное вычисление или хороший документ не доказывают загрузку координатора. Недоступные трассы чтения не оценены, а не доказывают отсутствие чтения. Сохранение требует проверенных записей; передача — доступных нужных результатов. Прерывание по квоте, доступность функции по тарифу и соблюдение инструкций различаются. [Матрица установки](installation.ru.md) разделяет загрузку пользовательских скилов, платные плагины, чат, среды с hooks и Codex CLI/Desktop. [Миграция/возврат](migration.ru.md) требуют будущего поручения.

# Исторические клиентские доказательства I06

Обновлено 27.10.2026. Исходники I06 (`0.0.0-i06`) опубликованы на GitHub в коммите `a8d124f77f77cb14ffcfca6abc0e839baee8fbd6`; проверенная база I05 — коммит `23a57e765494ab2480461e62843ed6c4c8716d37`. Лицензия и цены выбраны; продажи остаются закрытыми. Публикация не подтверждает установку или обновление клиента на Mac; эти проверки для I06 остаются невыполненными.

I06 добавляет ресурсы внутри папок скилов, уточнённые метаданные выбора md-word и совместное использование доступных форматных скилов, парную человеческую документацию и защиту профиля/вывода при изолированных путях. Исходные Word-файлы и схема профиля сохранены.

Владелец передал два разных наблюдения Claude: один исполнитель после чтения входных файлов сообщил об отсутствии ресурсов родительского дерева; другой видел описания, но выполнил задачу форматными скилами, не прочитав md-word. Точные среда/способ установки и полная трасса выбора неизвестны. Последующее объяснение второго агента — самоотчёт, а не независимое доказательство причинной ошибки description. Успешные файлы прогона без плагина не подтверждают его работу. Точный model ID, доступность по тарифам и гарантированный автоматический выбор не выводятся из этих сообщений.

Локальные регрессионные проверки охватывают ссылки изолированных папок, помощники, происхождение/актуальность ресурсов и сохранность синтетического внешнего профиля. Это проверки файлов и runtime, а не запуск в аккаунте Claude или реальное обновление клиента. Штатная валидация Claude Code и новый прогон I06 в целевой среде остаются отдельными проверками. См. [размещение ресурсов](skill-resources.ru.md).

Локальная проверка I06: 92 теста прошли (исходная база: 85). Дополнительный синтетический запуск отдельного агента с явно назначенным изолированным md-word прочитал встроенные инструкции, сохранил проверенный результат, состояние и журнал без итогового Word-отчёта. Возвращённые файлы просмотрены основным агентом. Это не проверка автоматического выбора и не запуск настоящего клиента Claude.

### Историческая запись просмотра I05

Записано 26.10.2026. Этот пакет — `0.0.0-i05`; на клиенте проверялась его база `0.0.0-i04`. I05 меняет документацию просмотра/статусов, техническую версию и соответствующие константы сборщика/теста. Runtime-скрипты, схемы, Word-файлы, описания входов, выбор языка и договоренности выполнения задач прежние. Установка или обновление I05 на Mac не заявлены.

| Проверка I04 | Доказательство и границы |
| --- | --- |
| Регистрация локального каталога, установка и включение | Владелец предоставил JSON Codex CLI 0.162.1 |
| Явные human-step и md-word | Ответы исполнителя называют ресурсы установленного кеша; возвращенные рабочие файлы просмотрены |
| Инструкции EN по умолчанию при RU-результате/журнале; явный RU | Перечни ресурсов исполнителя и фактические русские результаты |

| Общие шаблоны, помощник workspace и нейтральный Word-ресурс | Сообщенный успех помощника, возвращенные состояние/журнал и точные байты нейтрального DOCX |

| Явный профиль в свежем контексте | RU-инструкции выбраны из профиля; четыре сообщенных SHA-256 совпали с ранее возвращенным baseline; по ответу исполнителя PREPARE не выполнил назначенное будущее изменение |

Профильный сценарий сообщает macOS 26.5.2 arm64 и Python 3.14.5. Стенд сборки — Linux/Python 3.12. Это наблюдения, не минимальная версия Python и не гарантия для всех платформ. Интегратор не управлял Mac напрямую; сообщенные команды/чтения остаются атрибутированы исполнителю. Просмотр артефактов независимо подтверждает содержимое и согласованность файлов, но не всю историю действий файловой системы.

Одна ранняя проверка состояния выполнена последующим уточнением. Два поиска использовали неверные пути ресурсов и были исправлены. Один журнал не содержал метаданных атрибуции; следующий включил редакцию/версию и unknown для модели после явного поручения. Эти наблюдения не обосновывают новую архитектуру и не гарантируют будущее соблюдение инструкций агентом. Точные личные пути, переписка и профили остаются приватными.

## Оставшиеся границы

Установка/обновление I05 на Mac, отдельная опись picker, другие клиенты, Windows и Microsoft Word не проверены. Стадирование помощника с проверкой сохранности профиля не является реальным CLI upgrade. Установленным I04 можно продолжать пользоваться; повторные ручные проверки триггеров не нужны только ради просмотра кандидата. Фактическое обновление проверять при смене установленного пакета.

Для нейтральных Word-файлов по совпадению хешей сохраняются прежние рендер/визуальная проверка. Рендерер использовал Liberation Serif вместо объявленного шрифта; оформление в Microsoft Word этим не установлено. Визуальный отзыв владельца положительный, приложение просмотра не сообщено. Публичной публикации и внешнего push не было. Имя продукта, публичный автор, лицензия и версия выпуска остаются решениями для просмотра.
