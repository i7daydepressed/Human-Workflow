# Клиентские доказательства — кандидат I05 для просмотра

Записано 26.10.2026. Этот пакет — `0.0.0-i05`; на клиенте проверялась его база `0.0.0-i04`. I05 меняет документацию просмотра/статусов, техническую версию и соответствующие константы сборщика/теста. Runtime-скрипты, схемы, Word-файлы, описания входов, выбор языка и договоренности выполнения задач прежние. Установка или обновление I05 на Mac не заявлены.

| Проверка I04 | Доказательство и границы |
| --- | --- |
| Регистрация локального каталога, установка и включение | Владелец предоставил JSON Codex CLI 0.162.1 |
| Явные human-step и md-word | Ответы исполнителя называют ресурсы установленного кеша; возвращенные рабочие файлы просмотрены |
| Инструкции EN по умолчанию при RU-результате/журнале; явный RU | Перечни ресурсов исполнителя и фактические русские результаты |
| Неявные human-step и md-word | Обычные запросы выбрали ожидаемые установленные входы по сообщениям исполнителя |
| Объяснение понятия и обычная правка кода | Ответы сообщили отсутствие чтения скилов и ненужного отчетного процесса; исправленный код не приложен |
| Общие шаблоны, помощник workspace и нейтральный Word-ресурс | Сообщенный успех помощника, возвращенные состояние/журнал и точные байты нейтрального DOCX |
| Init, повторный init, экспорт и импорт профиля | Шесть записанных команд помощника с кодом 0; двенадцать сообщенных проверок; возвращенные профили, manifest, выбранный DOCX и исключения просмотрены независимо |
| Явный профиль в свежем контексте | RU-инструкции выбраны из профиля; четыре сообщенных SHA-256 совпали с ранее возвращенным baseline; по ответу исполнителя PREPARE не выполнил назначенное будущее изменение |

Профильный сценарий сообщает macOS 26.5.2 arm64 и Python 3.14.5. Стенд сборки — Linux/Python 3.12. Это наблюдения, не минимальная версия Python и не гарантия для всех платформ. Интегратор не управлял Mac напрямую; сообщенные команды/чтения остаются атрибутированы исполнителю. Просмотр артефактов независимо подтверждает содержимое и согласованность файлов, но не всю историю действий файловой системы.

Одна ранняя проверка состояния выполнена последующим уточнением. Два поиска использовали неверные пути ресурсов и были исправлены. Один журнал не содержал метаданных атрибуции; следующий включил редакцию/версию и unknown для модели после явного поручения. Эти наблюдения не обосновывают новую архитектуру и не гарантируют будущее соблюдение инструкций агентом. Точные личные пути, переписка и профили остаются приватными.

## Оставшиеся границы

Установка/обновление I05 на Mac, отдельная опись picker, другие клиенты, Windows и Microsoft Word не проверены. Стадирование помощника с проверкой сохранности профиля не является реальным CLI upgrade. Установленным I04 можно продолжать пользоваться; повторные ручные проверки триггеров не нужны только ради просмотра кандидата. Фактическое обновление проверять при смене установленного пакета.

Для нейтральных Word-файлов по совпадению хешей сохраняются прежние рендер/визуальная проверка. Рендерер использовал Liberation Serif вместо объявленного шрифта; оформление в Microsoft Word этим не установлено. Визуальный отзыв владельца положительный, приложение просмотра не сообщено. Публичной публикации и внешнего push не было. Имя продукта, публичный автор, лицензия и версия выпуска остаются решениями для просмотра.
