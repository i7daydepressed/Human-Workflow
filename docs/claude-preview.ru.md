# Установка в Claude

Устанавливайте тот же репозиторий из GitHub по [руководству](installation.ru.md). Корневой `.claude-plugin/marketplace.json` указывает на `./`; `.claude-plugin/plugin.json` описывает плагин. Сохраняйте его `skills/`, `locales/`, `shared/` и `docs/` вместе. Отдельный тестовый архив Claude не требуется. [English](claude-preview.en.md).

Фактическая установка в Claude и доступ к ресурсам еще не наблюдались. Возможности аккаунта/клиента определяют доступ к локальным файлам, сохранение профиля, Python, рендер и шрифты. После установки начните реальную задачу и сохраните фактические ошибки, если они появятся. Существующие сборщики архивов — необязательные инструменты разработки.
