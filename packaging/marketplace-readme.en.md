# Human-workflow-v0.0.7 — local marketplace

Русский (`README.md`)

This optional marketplace contains the same `human-workflow` plugin, version `0.0.7`, under `plugins/human-workflow/`. Normal installation uses the single repository <https://github.com/i7daydepressed/Human-Workflow>; users do not need a separate build.

See the plugin README (`plugins/human-workflow/README.en.md`) and check scope (`plugins/human-workflow/docs/client-checks.en.md`). The marketplace identifier is retained for compatibility. Updating it must not alter the external private profile. Extracting a directory does not establish client installation or an upgrade.

The separate preview catalog keeps its legacy name `workflow-preview-i04`; the repository catalog is `workflow-tools`. The plugin is Apache-2.0 licensed. This candidate is not published or host-installed by the build.
