# Human Workflow — local marketplace

Русский (`README.md`)

This optional marketplace contains the same `workflow-tools-preview` plugin, version `0.0.0-i06`, under `plugins/workflow-tools-preview/`. Normal installation uses the single repository <https://github.com/i7daydepressed/Human-Workflow>; users do not need a separate build.

See the plugin README (`plugins/workflow-tools-preview/README.en.md`) and check scope (`plugins/workflow-tools-preview/docs/client-checks.en.md`). The marketplace identifier is retained for compatibility. Updating it must not alter the external private profile. Extracting a directory does not establish client installation or an upgrade.
