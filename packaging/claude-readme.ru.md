# Workflow Tools — тестовое превью для Claude

Это тестовый пакет для Claude на основе кандидата I05. В нем human-step и md-word, парные инструкции EN/RU, один общий runtime и нейтральный Word-пресет. Отличается только упаковка; тела скилов, скрипты, схемы и Word-файлы сохраняют исходные байты. Имя/версия технические и временные. Публичные автор и имя выпуска не выбраны.

Установка описана в docs/claude-preview.ru.md и .en.md. Сохранять всю папку: скилы используют соседние locales, shared и docs. Это ZIP плагина, не отдельного скила. Установка Claude, доступ к ресурсам и поведение задач еще не проверены. Структурная/побайтовая проверка не заменяет запуск в клиенте.

Профили находятся вне установки/кеша и остаются явно выбранными файлами. Сохранение их между сессиями контейнера чата не обещано; отдельно выбрать хранение/перенос. Рендер Word и локальные зависимости зависят от хоста. Инструкции Codex в docs описывают прежние доказательства той платформы, а не совместимость Claude.

Для первого внешнего прогона подтвердить установку и оба скила, затем выполнить одну обычную задачу и вернуть фактический результат/ошибки. Прежнюю серию микротестов Codex повторять не требуется. Подачи в публичный каталог или публикации не было. PACKAGE-MANIFEST.json содержит происхождение файлов; личные оригиналы и профили исключены.
