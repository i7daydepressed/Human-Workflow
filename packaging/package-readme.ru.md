# Workflow Tools Preview — I05

Локальный пакет для просмотра: два workflow, инструкции EN/RU, общий runtime, внешний приватный профиль и нейтральный Word-пресет. Технические имя/версия временные; публичные бренд и автор не выбраны. Пакет не опубликован и не установлен настоящим клиентом.

После распаковки держать корневой `plugin.json`, `skills/`, `locales/`, `shared/` и `docs/` вместе. Полный плагин использует общие ресурсы за пределами отдельной папки скила. В `docs/installation.ru.md` (либо `.en.md`) описаны изолированный локальный каталог, запросы для проверки клиентом и требования. Описания входов рассчитаны на явный вызов и неявный подбор; обнаружение I04 имеет клиентские доказательства; установка/обновление I05 еще не проверены.

По умолчанию инструкции английские, в том числе при русском результате. Явное `instruction_language: ru` в задаче либо выбранный приватный профиль выбирает русский. Языки результата/журнала независимы. Для обычного выполнения обе редакции не загружать.

Из корня плагина можно вызвать локальные помощники; с абсолютным путем к скрипту — из другой рабочей папки:

```bash
python3 shared/scripts/report_workspace.py init /absolute/path/to/task --mode accompany --language ru
python3 shared/scripts/profile.py init /absolute/path/to/private-profile --instruction-language en --output-language ru --log-language ru
```

Профили и задачи хранить вне пакета/кеша. Установка/обновление их не перезаписывают. Основным помощникам нужен Python, замене титула дополнительно `lxml`. Рендерер, шрифт, облачный адаптер и универсальный MD→Word-конвертер не устанавливаются. Измеренные границы Word описаны в `docs/word-preset.ru.md`.

Исторический опыт по выбору владельца сохранен в повествовательной и JSON-форме. Это справочные материалы, не рабочий приватный каталог приемки и не доказательство новой сдачи. Исходные оригиналы, личные идентификаторы/цитаты/ссылки и профиль владельца исключены. `PACKAGE-MANIFEST.json` фиксирует исходные пути и хеши, не удостоверяя установку или публикацию.

База I04 проверялась в Codex CLI; этот пакет I05 еще не устанавливался/не обновлялся на Mac. Точная матрица и источники: docs/client-checks.ru.md.
